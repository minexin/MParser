# MParser v0.1-v0.76 Milestone Archive

This directory preserves the implementation notes and executable evidence for
the first 76 pre-v1 milestones. These files document design history; they do
not override the current compatibility matrix, public contracts, user manual,
or support matrix.

Milestones v0.77 through v0.90.1 remain in the parent `docs/` directory
because the v1 compatibility matrix and release evidence still cite those
contract-boundary audits directly.

Use the milestone filename matching the historical version, for example
[`v0.54.md`](v0.54.md). For current behavior, start at
[`../../README.md`](../../README.md).
