# MParser v0.55 Scope

MParser v0.55 adds guarded first-invocation JIT execution. Eligible closed
`for` loops no longer require a complete profiling VM run before native or
portable typed execution can be attempted.

## Milestone Contract

- Project and CLI version are `0.55.0`.
- `--run-jit` statically discovers closed loop regions and executes them with
  the selected typed backend on the first script invocation.
- Static discovery uses the same bytecode region analyzer as profile-guided
  compilation and only installs regions already accepted by its control-flow,
  mutation, call, and operation checks.
- Runtime loop-range, scalar, and array guards remain authoritative. A failed
  guard or failed native compilation resumes at the unchanged bytecode frame.
- Typed execution remains transactional: workspace updates are committed only
  after the complete region succeeds.
- `--run-typed-bytecode` retains its slower development contract: execute a
  profiling baseline, build Typed IR, execute it, and compare deterministic
  outputs.
- CLI reporting distinguishes skipped baseline validation from a successful
  baseline comparison.

## Commands

Fast first-invocation native execution:

```powershell
build\mparser.exe --run-jit --typed-backend=native `
  samples\timing_loop_demo.m
```

Portable guarded execution and profile-guided validation:

```powershell
build\mparser.exe --run-jit --typed-backend=portable `
  samples\nested_typed_loop_demo.m
build\mparser.exe --run-typed-bytecode --typed-backend=native `
  samples\timing_loop_demo.m
```

On the Windows x64 development machine, the nested million-iteration timing
sample reported approximately `0.0214` seconds inside `tic`/`toc` and `0.18`
seconds of fresh-process wall time. This is a local observation, not a portable
performance guarantee.

## Validation

- Optimization-plan tests cover static acceptance of a closed scalar loop and
  rejection of a loop containing an unsupported user call.
- CLI tests require guarded execution to enter the typed kernel and explicitly
  report that baseline validation was skipped.
- Existing profile-guided, adaptive, portable, native, fallback, cache, and
  cross-platform tests remain enabled.

## Next Iteration

- Infer additional safe numeric regions outside loops.
- Add persistent compiled-module and native-code cache artifacts with source,
  target architecture, ABI, and build-version invalidation.
- Reduce ordinary bytecode VM dispatch and `RuntimeValue` overhead.
