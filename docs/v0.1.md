# MParser v0.1 Scope

MParser v0.1 is a usable MATLAB-like frontend and reference interpreter
milestone. It is not a full MATLAB runtime, but it now has enough syntax,
semantic HIR, bytecode skeleton, and interpreter behavior to run meaningful
numeric scripts with functions, control flow, indexing, and recoverable runtime
diagnostics.

## Included

- Portable C++20/CMake project layout for Windows and Linux-oriented builds.
- Lossless lexer and syntax tree with modern MATLAB surface coverage,
  including `classdef`, attributes, properties, methods, events, enumeration
  blocks, functions, control blocks, matrix/cell literals, function handles,
  meta-class expressions, and neutral call/index nodes.
- Semantic HIR with scopes, local symbols, lazy builtin binding, local function
  predeclaration, class/member declarations, and delayed dynamic operations.
- Linear bytecode skeleton for parser/semantic/JIT handoff.
- Reference HIR interpreter for scalar doubles, numeric vectors, matrices,
  string literals, local functions, multiple-output destructuring, selected
  builtins, loops, branches, `switch`, `try`/`catch`, short-circuit logic, and
  1-based MATLAB-style indexing.

## Runtime Subset

The interpreter can execute:

- Assignments, local function calls, first-output calls, `[a, b] = f(...)`, and
  ignored outputs with `~`.
- `if`/`elseif`/`else`, `for`, `while`, `break`, `continue`, `return`,
  `switch`/`case`/`otherwise`, and `try`/`catch`.
- Numeric arithmetic, comparison, elementwise operations, transpose, basic
  matrix multiplication, and short-circuit `&&`/`||`.
- String literals, string equality with `==` and `~=`, and `strcmp`.
- Numeric ranges, vector/matrix literals, `zeros`, `ones`, `eye`, `linspace`,
  `sum`, `min`, `max`, `mean`, `any`, `all`, `length`, `numel`, and `size`.
- 1-based indexing, `end` inside indexing, colon subscripts, vector
  subscripts, linear indexing, and scalar assignment into existing numeric
  arrays.

## Explicit Gaps

The v0.1 runtime intentionally still reports diagnostics for:

- Class instances, constructors as runtime objects, object dispatch, and
  overloaded operations.
- Cell arrays and brace indexing execution.
- Function handle invocation.
- General dynamic path/package/static method lookup.
- Automatic array growth during indexed assignment.
- Complex numbers, sparse arrays, tables, structs, and broad MATLAB builtin
  compatibility.
- Executing bytecode and JIT compilation.

These are preserved as future layers rather than guessed incorrectly in the
reference interpreter.

## Next Iterations

The most valuable next steps are:

- Introduce an executing bytecode VM so the interpreter and future JIT share a
  stable execution target.
- Add profiling counters around loops and local functions to identify hot
  regions.
- Lower numeric hot loops to a typed IR with shape/type guards.
- Expand runtime data types for cells, structs, and class instances.
- Build a conformance corpus from real MATLAB scripts and expected diagnostics.
