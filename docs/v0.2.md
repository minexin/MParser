# MParser v0.2 Scope

MParser v0.2 turns the bytecode layer from a dump-only IR into a first
executable VM path. The HIR interpreter remains the broader compatibility
runtime; the bytecode VM is deliberately narrower and is intended as the
execution target that future profiling and JIT work can harden.

## Added Since v0.1

- `BytecodeVm` runtime over `BytecodeProgram`.
- `--run-bytecode` CLI mode.
- Jump-target bytecode for `if`, `for`, `while`, `break`, `continue`, and
  `return`.
- Bytecode VM smoke tests in `bytecode_vm_smoke`.
- `samples/bytecode_vm_demo.m` and `samples/bytecode_control_demo.m` as the
  supported VM demos.
- Project version and CLI version bumped to `0.2.0`.

## Bytecode VM Supported Subset

The v0.2 VM can execute:

- Single scripts and single no-argument functions.
- Scalar double values, strings, numeric vectors, and numeric matrices.
- Straight-line assignments to variables.
- Core control flow: `if`/`elseif`/`else`, `for` ranges, `while` loops,
  `break`, `continue`, and `return`.
- Matrix and vector literals.
- Numeric arithmetic, comparison, logical `&`/`|`, and scalar `&&`/`||`
  evaluation after lowering.
- Colon ranges with the two-term form `a:b`.
- Transpose.
- 1-based one-subscript and scalar two-subscript indexing.
- Selected builtins: `sin`, `cos`, `sqrt`, `abs`, `sum`, `size`, `length`,
  `numel`, `any`, `all`, `zeros`, `ones`, `eye`, `linspace`, and `strcmp`.

## VM Gaps

The VM intentionally reports diagnostics for features that need richer IR or
runtime metadata:

- `switch` and `try` control execution.
- Local function calls and runtime call frames.
- Multi-output assignment such as `[rows, cols] = size(A)`.
- Indexed assignment.
- `end` and colon subscripts inside indexing.
- Classes, object dispatch, member assignment, cells, brace indexing, function
  handles, structs, tables, sparse arrays, and complex values.

These remain covered, where implemented, by the HIR interpreter.

```powershell
cmake --build build
ctest --test-dir build --output-on-failure
build\mparser.exe --version
build\mparser.exe --run-bytecode samples\bytecode_vm_demo.m

build\mparser.exe --run-bytecode samples\run_demo.m

```

## Next Iterations

The next high-value v0.3 work is to make the bytecode VM cover calls and richer
MATLAB assignment semantics:

- Add frame metadata and call instructions for local functions.
- Add output-count metadata for multi-output calls.
- Move shared numeric runtime helpers out of `interpreter.cpp` and
  `bytecode_vm.cpp`.
- Extend indexed assignment and dynamic call/index dispatch in bytecode.
- Add profiling counters to bytecode blocks and lower hot straight-line regions
  toward a typed optimizing IR.
