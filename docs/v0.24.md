# MParser v0.24 Scope

MParser v0.24 turns the first useful portion of its existing `classdef`
frontend into bytecode VM behavior. The milestone is intentionally an object
foundation: constructors, property state, instance methods, and static methods
are executable without claiming full MATLAB object semantics.

## Added Since v0.23

- `RuntimeValueKind::Object` with a class name and recursive named field map.
- Class metadata collection from class boundaries, properties, methods, and
  `methods (Static)` attributes.
- Constructor calls such as `Meter(4)` create an object and execute the class
  constructor in the normal function-frame runtime.
- Direct property access, `obj.Value`, and direct variable-backed writes,
  `obj.Value = value`.
- Instance method dispatch with the receiver as the first method input.
- Static-method dispatch through the class name, including rejection of
  instance methods called as static methods.
- Object-aware diagnostic rendering, profiling kind names, output comparison,
  and typed-IR guard metadata.
- `samples/class_runtime_demo.m` and a sixteenth CTest target covering
  construction, property mutation, instance dispatch, static dispatch, and
  invalid static calls.
- Project and CLI version bumped to `0.24.0`.

## Example

```powershell
build\mparser.exe --run-bytecode samples\class_runtime_demo.m
```

Expected values:

```text
created = <Meter>
created_value = 2
meter = <Meter>
scaled = 15
```

## Current Limitations

- Class execution is provided by the bytecode VM; the reference HIR
  interpreter remains a non-object execution baseline.
- No inheritance, superclass dispatch, handle alias semantics, copy semantics,
  access-control enforcement, events, enumerations, dependent properties, or
  property validation.
- Property writes require a direct variable receiver such as `obj.Value = 1`.
- Methods that mutate their receiver do not yet propagate changes through
  handle-style aliases.
- Class methods and constructors are not `CompiledModule` entry functions;
  run a script that declares and uses the class in this milestone.
- Native machine-code JIT and non-scalar object layout remain future work.

## Validation

```powershell
cmake -S . -B build -G Ninja
cmake --build build --clean-first
ctest --test-dir build --output-on-failure
build\mparser.exe --version
build\mparser.exe --run-bytecode samples\class_runtime_demo.m
```

Expected version output:

```text
MParser 0.24.0
```

## Next Iteration

- Add handle/value ownership policy and receiver mutation propagation.
- Add property defaults, validation, and access-control checks.
- Add inheritance and superclass method lookup.
- Add multidimensional Cells and comma-separated-list expansion.
- Add package/path lookup plus executable method/constructor module entries.
- Introduce native LLVM ORC compilation on Windows and ARM Linux.
