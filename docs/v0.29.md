# MParser v0.29 Scope

MParser v0.29 turns retained MATLAB class-member attributes into executable
encapsulation rules. The bytecode class runtime now distinguishes stored,
constant, and dependent properties; enforces method, constructor, read, and
write visibility; and automatically dispatches `get.Property` and
`set.Property` methods.

## Major Capability

- Function headers preserve qualified property-access method names such as
  `get.Value` and `set.Value`. Attributes on a `methods(...)` block are copied
  to each declared method in syntax and HIR.
- Property `Access`, `GetAccess`, and `SetAccess` execute for `public`,
  `protected`, and `private`. `SetAccess = immutable` permits writes only from
  the defining class constructor.
- Method `Access` applies to instance methods, static methods, and constructors.
  Protected constructors are callable through a subclass construction chain;
  private constructors can be used by same-class factory methods.
- The runtime bases access on the currently executing method's declaring class,
  so inherited methods retain their original privileges and subclass methods
  receive protected, but not private, access.
- Overriding methods must preserve the inherited `Access` value.
- `Constant` properties require an explicit default, use the existing
  class-level default cache, support class-qualified and inherited reads, and
  reject later writes. Constant default expressions execute in their declaring
  class context and can reference private constants.
- `Dependent` properties allocate no object field and require a get method.
  Reads and writes dispatch through associated access methods, including for
  inherited properties.
- Property class/size/validator checks run before a set method. Assignment to
  the same property from its own get or set method bypasses recursive dispatch
  and repeated validation, matching MATLAB's access-method rule.
- Value-class set methods return the updated object. Handle-class set methods
  may return zero or one object and preserve shared field storage.
- `AbortSet` is executable for handle properties: assigning a runtime-equal
  value skips storage and the set method.
- Function frames preserve an input value when an output uses the same name.
  This fixes the common MATLAB contract `function obj = method(obj, ...)`.
- Project and CLI version are `0.29.0`; CTest now contains 21 targets.

## Access Method Contracts

A get method must accept one object and return one value:

```matlab
function value = get.PropertyName(obj)
```

A value-class set method must accept the object and proposed value and return
the updated object:

```matlab
function obj = set.PropertyName(obj, value)
```

A handle-class set method accepts the same two inputs and may omit its output:

```matlab
function set.PropertyName(obj, value)
```

Access methods must be declared in a `methods` block without attributes and
cannot be called as ordinary methods. Invalid signatures, access methods for
unknown properties, dependent defaults, missing dependent getters, and
constant properties without defaults produce diagnostics before script
execution.

The implemented ordering and recursion rules follow the corresponding MATLAB
class behavior:

- <https://www.mathworks.com/help/matlab/matlab_oop/property-attributes.html>
- <https://www.mathworks.com/help/matlab/matlab_oop/method-attributes.html>
- <https://www.mathworks.com/help/matlab/matlab_oop/property-set-methods.html>
- <https://www.mathworks.com/help/matlab/matlab_oop/access-methods-for-dependent-properties.html>
- <https://www.mathworks.com/help/matlab/matlab_oop/properties-with-constant-values.html>
- <https://www.mathworks.com/help/matlab/matlab_oop/validate-property-values.html>

## Example

```powershell
build\mparser.exe --run-bytecode samples\class_access_demo.m
```

Expected values include:

```text
calibrated = 80
identifier = 7
normalized = 4
scale = 10
value = 40
```

The sample uses a private stored field behind a validated dependent property,
a protected calibration value consumed by a subclass, an inherited constant,
and an immutable identifier written during construction.

## Current Limitations

- Class-list access values such as `Access = ?Friend` and
  `GetAccess = {?A, ?B}` are retained by the frontend but are not executable.
- Private/abstract property redeclaration, abstract members, sealed classes and
  methods, and complete override-compatibility rules are not implemented.
- `SetObservable`, `GetObservable`, listeners, property events, `Transient`,
  `NonCopyable`, dynamic properties, and handle lifecycle callbacks remain
  outside the runtime subset.
- `AbortSet` uses equality for the currently represented scalar, array, Cell,
  string, and object values. General MATLAB object-array equality is not yet
  available.
- Constant caches still live for one bytecode run rather than a persistent
  process-wide class-loader lifetime.
- Cross-file/package class loading and class definitions outside the same
  compiled source are not available.
- The reference HIR interpreter still does not execute class objects; these
  semantics belong to the bytecode runtime and future optimized tiers.
