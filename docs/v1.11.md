# v1.11 Host Debugger Development Batch

This internal batch addresses section 4 of the 2026-09-05
`MExecServer/docs/mparser-kernel-iteration-notes.md`: pause/breakpoints,
call-stack inspection, and function-local workspace inspection through the
public SDK. The frontend/backend repositories are read-only inputs to this
work. Product/SDK identity remains 1.3.0 until a later candidate stamp.

## Implemented Boundary

- Exact-source line breakpoints and thread-safe pending pause requests.
- Continue, step into/over/out, and non-catchable stop actions.
- Source ranges, caller call-site locations, frame kinds, input/output arity,
  and frame-local values including anonymous/global/persistent bindings.
- Dynamic stack ordering across temporary `eval` VMs and cross-module Runtime
  owner callbacks, plus default arguments and class initializer/method frames.
- C11 opaque debugger/event handles and header-only C++ RAII wrappers with
  owned event snapshots and normal module/Runtime Value ownership.
- Single-execution debugger admission, callback reentry/state-mutation rejection,
  callback error containment, and cancellation before resuming a paused statement.
- Existing execution-control suppression of Typed/native regions while debugging;
  no backend-specific debugger or new execution pipeline.

The public contract is [debugging-sdk.md](debugging-sdk.md). Source breakpoints
apply to executable statement lines, not comments/declarations. The host supplies
its own UI and pause command queue. Debug expression evaluation, local assignment,
conditional/exception breakpoints, MATLAB `db*` commands, `input`, and `keyboard`
are not implemented by this batch.

## ABI And Source Contract

C ABI generation 2 advances from revision 2 to revision 3 with 134 exports.
`mparser_invocation_options` adds a debugger pointer at offset 144 and is 152
bytes on the supported 64-bit platforms. The original 144-byte minimum remains
unchanged; missing tails are ignored. Fixed-stride breakpoint/frame records are
checked by the C11 layout test. No Parser, HIR, VM, RuntimeValue, or STL layout
is exposed as ABI. Existing archived public-contract snapshots stay immutable.

## Evidence

- `runtime_debugger_smoke`: HIR/VM step parity, pre-mutation stops, same-line
  columns, loop backedges, anonymous/session bindings, dynamic/cross-module
  stacks, live nested shared locals, callee-stop assignment/side-effect isolation,
  class/default frames, callback failure, and verifier rejection.
- `debugger_api_smoke`: Module/Session/Runtime paths under each requested backend,
  retained events/handles, two-thread pause/resume, concurrent/reentrant rejection,
  error containment, and pause-time cancellation.
- `debugger_c_api_smoke`: independent C11 callback, frame/variable inspection,
  retained local arrays, invalid arguments, and shorter caller-sized roots.
- `cpp_debugger_demo_smoke`: runnable breakpoint/step-into/step-out sample.
- Existing ABI export/layout, installed C11/C++20 consumer, lifecycle, allocation,
  compiler, VM, JIT, and CLI tests remain required.
