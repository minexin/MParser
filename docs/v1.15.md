# MParser 1.15 Host Integration Development

Status: development, not frozen or published. Product, CLI, C/C++ source API,
shared library and installed SDK identity is 1.15.0. C ABI remains generation 2,
revision 7 (146 exports); builtin source contract is 1.21 (356 descriptors,
358 registered names). The machine-result protocol remains 1.2. Graphics v3
is an explicitly selected snapshot format, not a new product version.

## Kernel Changes

- Compile-time rejection and diagnostics for empty assignment RHS and keyword
  assignments, plus side-effect-free SDK identifier validation.
- Compiler-produced function/local/nested/method definition metadata with
  hierarchy, source identity and UTF-8 byte ranges.
- Current Figure/Axes lifecycle, matrix plotting and handle arrays, bound Text
  labels, grids, automatic Legend entries and per-Line Clipping properties.
- Opt-in graph/object identities in immutable result snapshots and value
  snapshots, without changing legacy v1/v2 output.
- Explicit headless print/saveas validation and renderer-unavailable errors;
  no PNG/PDF encoder or browser-based command substitution is provided.

## Evidence And Remaining Work

The 1.15.0 development binaries were freshly rebuilt and passed 347/347 local
checks, including the simulated renderer replay with real kernel snapshots,
installed C/C++ consumers and archive checks. Both build-tree and relocated
CLI output reported MParser 1.15.0. An isolated host built from the installed
1.15.0 SDK passed 67/67 host tests and dedicated REST probes, including exact
runtime product-version and ABI checks. These are local development results,
not an authenticated release or full downstream deployment approval.

Real-browser visuals, deployed host adoption, client source navigation,
protocol negotiation and persistent property writeback remain open. Read the
live [host acceptance matrix](host-integration-goal-20261028.md) rather than
treating passing kernel tests as completed host or MATLAB compatibility.

## Contract Selection

The active installed MParser_PUBLIC_CONTRACT_FILE points to
host-integration-contract-development.json, which is explicitly development
state and pins live SDK artifacts. MParser_BASELINE_PUBLIC_CONTRACT_FILE points
to immutable public-contract-v1.14.json. The v1.14 release tag, frozen C/C++
headers and historical protocol/catalog snapshots are unchanged.

No v1.15 tag, GitHub release, authenticated release archive or production SDK
update is established merely by this version increment.
