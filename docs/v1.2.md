# MParser v1.2.0 Candidate

MParser v1.2 is the core runtime, numeric, and host-integration train after the
v1.1 semantic corrections. It is an internal release candidate rather than a
claim of complete MATLAB compatibility. The milestone freezes one coherent
current SDK without adding adapters for superseded development interfaces.

## Scope

The completed train provides:

- C source API 1.2 and header-only C++ source API 1.2 over C ABI generation 2
  revision 0, with in-memory sources, search/class paths, source metadata,
  retained expression results, and synchronous host output;
- dense `double`, `single`, `logical`, every fixed-width signed/unsigned
  integer class, and dense complex double/single values through RuntimeValue,
  Interpreter, bytecode VM, C/C++ APIs, and machine protocol 1.1;
- exact base literals and exact 64-bit integer transport, including a portable
  binary80-equivalent path for mixed `int64`/`uint64` and scalar-double
  arithmetic without binary64 precision loss;
- shared conversion, saturation, rounding, promotion, comparison,
  concatenation, indexing, assignment, reduction, and diagnostic authorities;
- a coherent elementary math/predicate/constructor tranche through the
  BuiltinRegistry rather than per-engine switches;
- strict array-aware numeric text parsing, row-structured multidimensional
  Cell literals, and first-class scalar/N-dimensional missing arrays;
- guarded portable/native eligibility with transactional VM fallback for every
  newly legal value class that Typed IR does not yet represent.

The missing implementation illustrates the milestone rule: `missing` creates
a 1-by-1 value, while ordinary concatenation, transforms, indexing, mutation,
conversion, embedding, and protocol paths support shaped missing arrays.
`[missing missing]` is therefore a normal 1-by-2 matrix construction, not a
parser or test-case exception.

## Candidate Contract

The current boundary is frozen in `docs/public-contract-v1.2.json`:

| Boundary | Candidate identifier |
| --- | --- |
| Product and installed SDK | 1.2.0 |
| Production CLI | 1.0 |
| C source API | 1.2.0 |
| C ABI | generation 2, revision 0; 109 symbols; SOVERSION 2 |
| C++ source API | 1.2, header-only C++20 |
| Machine result protocol | `mparser.result` 1.1 |
| Builtin source contract | 1.1; 166 descriptors, 168 registered names |

The C/C++ header snapshots, generation-2 symbol list, builtin catalog, machine
protocol fixtures/schema, CLI contract, package metadata, and normalized
SHA-256 values are checked by `v1_2_public_contract_smoke`. The v1.0 files
remain immutable historical evidence and are not rewritten for this candidate.

## Runnable Evidence

Representative user-visible paths are:

```text
mparser --run samples/numeric_types_demo.m
mparser --run samples/complex_numeric_demo.m
mparser --run samples/core_numeric_builtins_demo.m
mparser --run samples/text_runtime_demo.m
mparser --run samples/host_integration_demo.m
```

The stable summaries are respectively `6`, `1`, `0`, `49`, and `103`.
Each applicable sample is also exercised through the reference HIR path,
no-JIT bytecode, portable typed execution, and native SLJIT with guarded
fallback rather than type coercion for optimization.

## Differential Evidence

The unchanged MATLAB R2024b reference accepts all 223 external cases. The
v1.2 rerun in
`MParserV1.0Test/results/20260811-190359-v1.2-mixed-int` reports 169 matches
and 54 categorized gaps, up from 140 matches at the v1.1 boundary. No previous
match regressed. The closed cases cover exact base syntax, missing/string
types, row-shaped Cells, arithmetic/parser distinctions, finite/rounding and
shape predicates, `mod`/`rem`, `nextpow2`, and recursive `isequaln` behavior.

Repository tests go beyond those individual cases: numeric classes and missing
values cover scalar and N-dimensional shapes, boundaries, mixed-class rules,
invalid conversion, indexing/mutation, APIs/protocol, and JIT guard fallback.

## Validation Boundary

The candidate freeze passes 226 native Release tests, 217 clean no-JIT tests,
and 218 MSVC ASan no-JIT tests. The native and sanitizer suites include the
independent installed C11/C++20 consumer gates; the separate release archive
gate also passes reproducible two-pass packaging, provenance and checksum
validation, unpacked CLI execution, and relocated consumer builds. The complete
223-case MATLAB R2024b differential rerun records 169 matches and 54 known gaps
with no regression from the imported baseline. Cross-platform counts are
recorded by the freeze commit's CI run rather than inferred from local checks.

v1.3 now owns session-scoped system services, text/order/set/array/random and
other broad standard-library functions. Advanced statistics, linear algebra,
FFT/convolution, optional mature backends, and wider Typed/JIT coverage remain
the coherent v1.4 train.
